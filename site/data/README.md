# Future 40 catalogue data

Three files back the site, all plain JSON so anyone can audit the claims directly.

## `companies.json` — roster membership

The eight official STATION F Future 40 cohorts (2019-2026, 40 names each = 320 companies), each tied to the one official STATION F announcement page that names that cohort (`sourceUrl`). This file only establishes **membership** — that a company was named in that year's Future 40.

## `enrichment.json` — product description at selection

Generated by `scripts/enrich-from-stationf.mjs`, which re-fetches each `sourceUrl` from `companies.json` and extracts, for every company it can find in the page, the short product description STATION F itself published next to that company's name, plus the company website STATION F linked at the time (if any). Every entry carries a `source` object (`url`, `label`, `verifiedAt`) pointing straight back to the roster page and the date it was last re-verified.

This description is **historical** — it reflects the company as STATION F described it in the year of selection, not necessarily today.

## `facts.json` — additional sourced facts

An optional, manually-curated layer for fields the roster page does not cover: founders, funding, investors, geography, current status. Keyed as `"<year>|<company name>"`, each entry is an array of facts, and each fact stands on its own:

```json
{
  "field": "funding",
  "value": "Raised a €4M seed round led by Example Capital (2024).",
  "source": {"label": "Example Capital press release", "url": "https://…"},
  "verifiedAt": "2026-11-18"
}
```

Rules for adding a fact here:

- One fact, one field, one claim — do not bundle multiple unrelated claims into a single `value`.
- `source` must be a **named primary source**: the company's own site or press release, an investor's press release, an official STATION F publication, or a relevant government/company registry.
- LinkedIn, Crunchbase, other aggregators, news round-ups, or inference from unrelated facts are never acceptable as the sole evidence for a fact. If the only thing you can find is an aggregator listing, leave the field out.
- `verifiedAt` is the date *you* checked the source, not the date the source itself was published.

As of the last data refresh, `facts.json` is empty — no founder, funding, investor, geography or status claim has been added yet for any of the 320 companies. That is intentional: the catalogue would rather show nothing than something unverified.

## Verification policy

- Every roster entry has one official STATION F source establishing Future 40 cohort membership.
- Product description and website are shown only when extracted from that same official source, with a link back to it and a verification date.
- Founders, funding, investors, geography and current status are shown only when `facts.json` carries a specifically-sourced entry for that company and field.
- Any field without a qualifying source is left off the page. The site never renders an "Unverified" placeholder for a missing field — absence of a field *is* the signal.
- The sector shown on each card is this catalogue's own editorial grouping, computed from the product description, and is explicitly labelled as not an official STATION F classification.
